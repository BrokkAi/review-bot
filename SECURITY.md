# Security Policy

Report suspected vulnerabilities privately to
[feedback@brokk.ai](mailto:feedback@brokk.ai). Include the affected version or
commit, impact, and steps to reproduce. Remove credentials, personal data,
and private repository contents from reports and logs.

Do not post vulnerabilities or working exploits in public issues. Use public
issues for ordinary bugs; see [CONTRIBUTING.md](CONTRIBUTING.md).

The bot launches coding agents and commands with your operating-system and
repository permissions. Review its configuration and use an appropriately
isolated environment for untrusted repositories.
